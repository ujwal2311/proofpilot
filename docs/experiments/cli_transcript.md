# CLI transcript — the HARD GATE, played end to end

Generated by the commands below on 2026-10-12. The CLI drives `core` through the shared edge
(`app/`): no HTTP server, no React, no database. That is the point of this gate — if the tutor
needed the web layer in order to work, logic would have leaked out of `core` and the API would not
be a thin transport.

```powershell
cd backend
"c2 c3 = A`nhint`nhint`nhint`nc1 c2 = B`nc3 c4 =" | Set-Content -Encoding utf8 t1.txt
"hint`nhint`nhint`nno"                            | Set-Content -Encoding utf8 t2.txt
python -m src.cli --exercise ex-01 --script t1.txt
python -m src.cli --exercise ex-11 --script t2.txt
```

`--script` replays newline-separated commands through the *same* loop an interactive session uses,
so what follows is what a student at a terminal sees. `--exercise` pins one exercise rather than
letting the bands choose, because a does-not-follow exercise sits in the short band while a student
who has just proved something is in the long one.

**What to look for.**

1. **The deliberate mistake is NAMED, not refused.** `c2 c3 = A` returns `NO_CLASH` with the
   reason, and it costs CLASH alone (30% → 19%) because that is the only skill the step observed.
   "Wrong" would teach nothing; naming it is the formative premise of the project.
2. **The ladder escalates.** Level 1 names one clause, level 2 names both, level 3 hands over the
   resolvent. The resolvent is not merely hidden from the display — it is **absent from the hint
   object** below level 3, so it cannot leak through any client.
3. **Help is not free.** The two correct steps after three hints are scored as *hinted*: mastery
   falls to 17–19% before the solve. That is §9's hint rule, visible end to end.
4. **Session 2 runs no search at all** (§6.6, V-2). The empty clause is unreachable, the truth
   table already settled it, and the `HINT_NOT_FOLLOW_*` ladder redirects the student toward the
   right *action*. The accepted claim still scores STRATEGY **wrong**, because a hint was taken —
   exactly as §9 states, and the one row that reads like an exception but is not.
5. **Nothing is deleted.** On a long exercise the irrelevant premises stay on the board, marked
   "not needed for this conclusion" (§6.5). The student may still use any clause.

Every sentence in this transcript comes from `data/messages.yaml`. `cli.py` contains no wording at
all, and `test_adapters_hold_no_user_facing_wording` fails the build if any appears.
